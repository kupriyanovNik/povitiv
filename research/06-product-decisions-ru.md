# Продуктовые решения: версия для РФ (зафиксировано 14.08.2026, обновлено: каналы = email + MAX)

Основание: фактчек [05-ru-adaptation.md](05-ru-adaptation.md).

## Принятые решения

| # | Решение | Почему |
|---|---------|--------|
| 1 | Прод и демо — на VPS в РФ (провайдер из реестра РКН). Vercel остаётся только dev-превью для нас | IP Vercel блокируются провайдерами РФ; демо с vercel.app может не открыться у клиента |
| 2 | Заявка = запись, а не сообщение: сначала журнал на сервере в РФ, потом уведомления | Надёжность (ничего не теряется) + локализация по 152-ФЗ + доказательство согласия |
| 3 | Каналы уведомлений: email через российский SMTP (основной) + бот в MAX админу (вторичный), с ретраями. Зарубежный Telegram-релей НЕ делаем | Полностью российский стек: ничего не блокируется, нет трансграничной передачи, нет лишнего зарубежного VPS. MAX Bot API: platform-api2.max.ru, бот через @MasterBot, 30 rps (dev.max.ru/docs-api) |
| 4 | Согласие на ПДн: отдельный неотмеченный чекбокс в обеих формах + лог факта (дата, время, IP) в журнале | Практика РКН 2025-2026: текст «нажимая кнопку» без чекбокса и лога = нарушение |
| 5 | CTA для посетителей: только форма и телефон (+ вариант задачи «Перезвоните мне»). Никаких ссылок «написать в WhatsApp/Telegram» | Мессенджеры у посетителей нестабильны; аудитория 35-60 звонит; битая ссылка подрывает доверие |
| 6 | Сборка артефакта вне РФ, шрифты (Golos, Geologica) самохостом в репозитории | GitHub/Google Fonts из РФ деградированы; сборка на РФ-VPS может падать |
| 7 | Яндекс-экосистема: Вебмастер, Яндекс.Бизнес, Schema.org (RealEstateAgent + Offer), встроенная Яндекс.Карта в контактах | Основной поисковик и карты аудитории |
| 8 | Прод-домен: positiv-vt.ru (домен клиента, индексация с 2011). namoderku.online — под демо | SEO-история + бренд |
| 9 | Никакого Cloudflare-прокси; SSL: Let's Encrypt, план Б — HARICA | Cloudflare режется до 16 КБ с 06.2025; LE пока выдаёт .ru |

## Открытые развилки (ждут решения клиента)

- **A. CRM**: есть amoCRM/Битрикс24? → вебхук в CRM. Нет → мини-админка `/admin` на сайте (список заявок + статусы).
- **B. Аналитика**: Яндекс.Метрика (потребует cookie-баннер с блокировкой скрипта до согласия) или серверный счётчик без кук.
- **C. SMS о горячих лидах**: подключать ли SMS-шлюз (SMS.ru/SMSC, ~0,5-3 ₽/сообщение).

## Задачи клиента (не код)

1. Подать уведомление РКН об обработке ПДн (pd.rkn.gov.ru через Госуслуги, ~час). Штраф за неподачу с 30.05.2025: 100-300 тыс. ₽.
2. Создать бота в MAX через @MasterBot (/create, получить токен) и нажать Start у бота с аккаунта менеджера (мы заберём chat_id). Процедура один в один как делали с Telegram.
3. Дать SMTP-ящик для уведомлений (или завести на Яндекс 360 / VK WorkSpace).
4. Ответить на развилки A-C.
5. Доступы: VPS (или заказать новый из реестра РКН, 2 ГБ ≈ 550-1000 ₽/мес), DNS positiv-vt.ru.

## Бэклог реализации (наш, по порядку)

1. **Лид-пайплайн v2** (ядро): журнал заявок на сервере (JSONL + согласие/IP/время) → email (SMTP из env) → MAX-бот (MAX_BOT_TOKEN/MAX_CHAT_ID) → ретраи с очередью. Существующий Telegram-канал остаётся в коде как опция для не-РФ деплоев (демо на Vercel), на РФ-проде просто не включается.
2. **Чекбокс согласия** в LeadForm и LeadModal, прокидка в API и журнал.
3. **Самохост шрифтов** (next/font/local, woff2 в репо).
4. **SEO-пакет**: Schema.org, sitemap.xml, robots.txt, метаданные на positiv-vt.ru.
5. **Деплой-кит РФ-VPS**: сборка артефакта в CI/локально, systemd + nginx + certbot, cron синка, инструкция.
6. **Демо на РФ-площадку** (поддомен demo.* или российский PaaS).
7. Обновить тексты privacy/consent под новую схему (журнал, каналы, куки).
8. По итогам развилок: админка или CRM-вебхук; Метрика с баннером или серверный счётчик; SMS.
