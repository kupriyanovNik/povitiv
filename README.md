# Позитив ВТ: продающий лендинг агентства недвижимости

Лендинг московского агентства недвижимости «Позитив ВТ» (ООО «Агентство «Позитив ВТ», ИНН 7707723617). Next.js 16 (App Router) + Tailwind v4 + Motion. Рейтинг и отзывы на странице реальные (Домклик, Яндекс Карты), хранятся в `data/` и правятся руками.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Продакшен:

```bash
npm run build
npm start
```

## Данные

Сайт читает JSON-файлы из `data/` **с диска в рантайме** ([lib/data.ts](lib/data.ts)), поэтому правка файла на сервере видна без пересборки.

- `data/agency.json` — рейтинг и отзывы агентства (Домклик)
- `data/reviews-external.json` — отзывы с Яндекс Карт и других площадок

Оба файла правятся руками и едут на сервер с каждым деплоем. Объекты в работе и их автоматический сбор с ЦИАН и Домклик убраны по решению клиента (26.10.2026); синка и ночного таймера больше нет.

Фото на сайте (`public/photos/`) сняты агентством, EXIF с геоданными вычищен.

## Заявки: журнал + email

`POST /api/lead` принимает `{ name, phone, task, consent, object?, comment? }`.
Пайплайн ([lib/leads.ts](lib/leads.ts)):

1. **Журнал на сервере** (обязательный шаг): заявка пишется в JSONL
   `data/leads/leads-ГГГГ-ММ.jsonl` (путь настраивается `LEADS_DIR`;
   дефолтный путь затирается при обновлении — HANDOFF раздел 10) вместе с
   фактом согласия (дата, время, IP). Это требование 152-ФЗ о первичной записи
   ПДн в РФ и страховка от потери лидов. Каталог в git не попадает.
2. **Уведомление на почту** — единственный канал (решение клиента 26.10.2026,
   MAX и Telegram убраны). SMTP ящика positiv-vt@mail.ru, настройки `SMTP_*`
   и `LEAD_EMAIL_TO` в `.env` (см. `.env.example`), две попытки с паузой.
   Без `SMTP_HOST`/`LEAD_EMAIL_TO` отправка пропускается.
3. Валидация, honeypot, rate-limit 5/мин c IP; без отметки согласия заявка
   отклоняется.

Заявка считается принятой, если записалась в журнал или ушла на почту. На
Vercel файловая система только для чтения и SMTP не настроен, поэтому на
демо форма отвечает ошибкой.

## Превью ссылки

Картинка, которую показывают мессенджеры и соцсети, — `public/og.png`, фирменная карточка 1200×630. Всё содержимое в центральном квадрате: Telegram в компактном превью режет картинку до квадрата. Перегенерировать после смены текста или телефона: `npm run og` (шаблон `scripts/og/card.html`). Telegram кеширует превью — обновить через @WebpageBot.

## Карта в подвале

Компонент [components/OfficeMap.tsx](components/OfficeMap.tsx) выбирает вариант по `YANDEX_MAPS_API_KEY`:

- **ключ задан** — карта на JS API Яндекс Карт 3.0 ([components/map/](components/map/)): схема перекрашена под палитру сайта (`mapStyle.ts`), вместо метки плашка агентства с телефоном и маршрутом, скрипт Яндекса грузится только на подходе к подвалу;
- **ключа нет или JS API не загрузился** (неверный ключ, домен не в ограничениях ключа, сеть) — бесплатный виджет Яндекс Карт.

Ключ читается в рантайме, поэтому после правки `.env` достаточно рестарта сервиса. Ограничения Яндекса: логотип, копирайты и кнопку «Открыть в Картах» нельзя скрывать и перекрывать; реклама на бесплатном тарифе возможна в обоих вариантах, отключается платным тарифом «Базовый (без рекламы)», 20 000 ₽/год.

## Деплой

Сайт размещается у хостинга агентства (Ниагара Стар). Инструкция для
администраторов — [deploy/HANDOFF.md](deploy/HANDOFF.md): требования, установка
на Windows (служба + Apache 2.4) и Linux ([README-VPS.md](deploy/README-VPS.md)),
настройки `.env`, переключение домена, проверка.

Архив для передачи собирается вне сервера: `./deploy/build-artifact.sh`
(`SKIP_NPM_CI=1` — из уже установленных `node_modules`, без скачивания).
Шрифты самохостятся (fontsource), сборка не обращается к Google Fonts.

## Структура

```
app/
  page.tsx            # сборка лендинга из секций
  api/lead/route.ts   # приём заявок
  privacy/, consent/  # юридические страницы
components/           # секции: Hero, Tasks, DealRoute, PropertyTypes, Team, Reviews, BankPartners, LeadForm, FAQ...
  lead/               # контекст модалки заявки + отправка
data/                 # agency.json, reviews-external.json (правятся руками)
lib/legal.ts          # тексты политики и согласия от клиента
lib/site.ts           # контакты, реквизиты, ссылки на профили
public/photos/        # фото города и домов (сняты агентством)
research/             # досье на агентство, структура, контент-дайджест, заметки по парсингу
```
