# Позитив ВТ — сайт агентства недвижимости

Полностью статичный сайт: `index.html` + `styles.css` + `script.js` +
картинки и шрифты. Без Node.js, без сборки, без внешних зависимостей —
работает на любом веб-сервере.

## Структура

```
index.html        — главная страница
privacy.html      — политика обработки персональных данных
consent.html      — согласие на обработку данных
404.html          — страница «Такой страницы нет»
styles.css        — все стили
script.js         — весь интерактив (меню, модалка, FAQ, карусель, форма)
robots.txt        — правила индексации
sitemap.xml       — карта сайта
img/, fonts/      — картинки и шрифты
README-hosting.md — инструкция по размещению для хостинга/администратора
research/          — рабочие материалы проекта (не часть сайта)
```

## Локальный просмотр

Открыть `index.html` в браузере или поднять любой статичный сервер,
например: `python3 -m http.server 3000`.

## Публикация и форма

Инструкция для хостинга — [README-hosting.md](README-hosting.md):
требования (любой веб-сервер + HTTPS), деплой, 404, редиректы старых
адресов.

Форма заявки: сабмит вызывает `window.submitLead(formData)`
(`script.js`) — **зарезервированная пустая функция**. Отправку заявок
подключает сторона, выполняющая деплой: замените тело функции
(например, на `fetch(...)` в свой обработчик).
